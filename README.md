# Непарадный Васильевский остров

Интерактивный путеводитель по Васильевскому острову Санкт-Петербурга: **23 тематические остановки**, карта OpenStreetMap + Leaflet, история, интересные факты, ссылки на исторические фотографии и первоисточники, поиск и фильтрация.

**Сайт:** https://smakara1.github.io/vasilevsky-guide/

## Включение GitHub Pages
Откройте **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**. Через несколько минут сайт будет доступен по указанному адресу. Публикацию Pages через доступный GitHub-коннектор здесь включить нельзя.

## Источники и корректность
- `data.js` — единая база остановок, описание, примерные координаты и источники.
- Географические точки **не следует считать точными адресами входов**: пройдите полевую проверку, особенно внутри кладбища.
- Полилиния соединяет ориентиры **по прямой**, не заменяет навигацию через тротуары/мосты.
- Исторические иллюстрации с Wikimedia Commons являются **видами района**, если не подтверждена фотография именно здания. Ссылки проверяйте вручную, лицензии объектов могут различаться. Если изображение не найдено — карточка сохранит ссылку на архив.
- Некоторые ссылки в `sources` указывают на справочные страницы или каталоги, не являются доказательством каждого факта. Сверяйте адреса и атрибуции перед печатью.
- Открытые архивные каталоги: [PastVu](https://pastvu.com/), [Wikimedia Commons](https://commons.wikimedia.org/), [РНБ](https://nlr.ru/), [Президентская библиотека](https://www.prlib.ru/), [ЭтоМесто](http://www.etomesto.ru/).

## Android
В папке `android/` — проект Android Studio: приложение WebView, открывающее опубликованный сайт (для работы необходим интернет). Отображение сайта поддерживает масштабирование, ссылки на карты и geolocation в браузере. Сборка APK доступна через GitHub Actions (**Actions → Build Android APK → Run workflow**); ZIP проекта также можно скачать на GitHub в **Code → Download ZIP**.

Убедитесь, что GitHub Pages включён, прежде чем устанавливать Android приложение.

Для офлайн-карты и офлайн-изображений потребуется отдельный релиз с локальными тайлами, подтверждёнными правами на фото и локальной копией сайта.
